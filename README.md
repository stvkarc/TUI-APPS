# TUI APPS

A personal collection of the best Terminal User Interface (TUI) tools for Linux.

This repo is meant to be a simple reference list for productivity, file management, system monitoring, and terminal workflows.

## Featured Picks

### File Manager
<details>
<summary>📁 Yazi</summary>

- Blazing-fast terminal file manager
- Written in Rust
- Built-in image/video preview support
- Vim-like keybindings
- Great for keyboard-first users

</details>

### Text Editors
<details>
<summary>📝 Helix</summary>

- Modern text editor with multiple selections
- Tree-sitter integration for syntax highlighting
- Built-in LSP (Language Server Protocol) support
- Fast and responsive

</details>

<details>
<summary>📝 Neovim</summary>

- Hyperextensible Vim-based editor
- Lua scripting for customization
- Large plugin ecosystem
- Modern terminal support

</details>

<details>
<summary>📝 Vim</summary>

- Classic, lightweight text editor
- Available on almost all Unix systems
- Steep learning curve but powerful once mastered
- Modal editing paradigm

</details>

### Git & Repo Tools
<details>
<summary>🔀 Lazygit</summary>

- Simple git commands in a user-friendly TUI
- Stage individual hunks
- Interactive rebase support
- Merge conflict resolution

</details>

<details>
<summary>🔀 Gitui</summary>

- Fast and intuitive Git GUI
- Blazing-fast Rust implementation
- Keyboard-driven workflow
- Lightweight alternative to Lazygit

</details>

<details>
<summary>🔀 Tig</summary>

- Git repository browser
- Explore commit history
- View file changes over time
- Scriptable with shell integration

</details>

### System Monitoring
<details>
<summary>📊 btop</summary>

- Modern resource monitor
- GPU monitoring support
- Disk I/O and network stats
- Colorful, easy-to-read interface

</details>

<details>
<summary>📊 htop</summary>

- Interactive process viewer
- More user-friendly than top
- Process sorting and killing
- Lightweight and fast

</details>

<details>
<summary>📊 glances</summary>

- System monitoring tool
- CPU, memory, disk, network stats
- Can be used locally or remotely
- Python-based, highly configurable

</details>

### Terminal Multiplexers
<details>
<summary>🔲 Tmux</summary>

- Terminal multiplexer for managing sessions/windows
- Detach and reattach sessions
- Highly scriptable
- Wide plugin ecosystem

</details>

<details>
<summary>🔲 Zellij</summary>

- Modern terminal multiplexer
- User-friendly layout system
- Plugin support
- Better defaults than Tmux

</details>

<details>
<summary>🔲 Screen</summary>

- Classic terminal multiplexer
- Simple and lightweight
- Works on almost all systems
- Less feature-rich but battle-tested

</details>

### Shell & UX
<details>
<summary>🐚 Fish</summary>

- User-friendly shell
- Auto-completion out of the box
- Syntax highlighting
- Easy to learn

</details>

<details>
<summary>🐚 Zsh</summary>

- Advanced shell with powerful customization
- Framework support (oh-my-zsh)
- Plugin system
- Good balance of power and usability

</details>

<details>
<summary>✨ Starship</summary>

- Minimal, blazing-fast prompt
- Cross-shell support (Bash, Zsh, Fish, etc.)
- Language and Git status detection
- Highly customizable

</details>

### Search & Productivity
<details>
<summary>🔍 Fzf</summary>

- Fuzzy finder for command line
- Search files, history, processes
- Integrates with shells and editors
- Fast and lightweight

</details>

<details>
<summary>⚡ Ripgrep</summary>

- Fast grep alternative written in Rust
- Respects .gitignore by default
- Recursive search with smart defaults
- Blazing fast on large codebases

</details>

<details>
<summary>🎨 Bat</summary>

- Cat clone with syntax highlighting
- Git integration to show diffs
- Automatic paging
- Line numbers and styling

</details>

<details>
<summary>📋 Exa / Lsd</summary>

- Modern replacement for ls command
- Colorful output by default
- File type icons (Lsd)
- Better readability

</details>
